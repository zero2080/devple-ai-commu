한글 픽셀 폰트 자산 준비 가이드

devple-ai-commu · 2026-09-30 · 작성: Claude Code · 대상: GRAPHICS 5.1(폰트)·5.2(말풍선)·5.3(닉네임), ROADMAP 7단계 · 실측: npm 패키지 다운로드 후 fontTools로 글리프 수 확인

결론. 후보 두 종 모두 SIL OFL 1.1이고 현대 한글 11,172자를 전부 갖고 있어 어느 쪽이든 쓸 수 있어요. 말풍선·닉네임 크기(2x 줌 기준)와 파일 크기를 고려하면 Galmuri11을 한글·라틴·문장부호만 남겨 부분집합으로 만들고 내부 이름을 바꿔 동봉하는 안을 추천해요. 이 결정은 GRAPHICS 5.1(chat 담당)에 기록돼야 하므로 docs/handoff/to-chat/에 요청을 남겼어요. 사용자가 할 일은 폰트 선택 1가지뿐이고, 파일 준비는 아래 절차대로 Claude Code가 7단계에서 수행할 수 있어요.

2026-09-30 결정. 사용자가 추천안(Galmuri11 부분집합 → PixelKo)을 채택했어요. 3장 절차대로 scripts/fonts/build-pixelko.sh가 src/assets/fonts/PixelKo.woff2(약 156 kB, 한글 11,172자·ASCII 95자, 검수 통과)와 OFL-Galmuri.txt를 만들었고, src/assets/LICENSES.md·index.css(@font-face, --pixel-font-em: 12px)에 반영했어요. GRAPHICS 5.1 기록은 chat에 요청했어요.

참고: GRAPHICS 5.1의 예시 "11px 폰트 → 2x에서 22px"는 Galmuri11의 실제 em이 12px이므로 24px가 맞아요. 규칙은 "폰트의 em 크기 × 줌"으로 적는 게 정확해요.

2. 추천과 근거

추천: Galmuri11 부분집합 + 내부 이름 변경 (family PixelKo)

  • 말풍선·닉네임 크기가 캐릭터(2x에서 64px 높이)와 균형이 맞아요. Neo둥근모는 32px라 이름표가 캐릭터 절반 높이예요.
  • 한자 6,477자는 이 서비스에 필요 없어요. 한글·자모·라틴·문장부호만 남기면 약 170 kB가 돼요 (같은 범위의 Galmuri11 Bold가 166.6 kB라 추정 정확도 높음).
  • OFL 예약 이름 규칙: 부분집합은 "수정본"이라 파일 내부 이름에 Galmuri를 쓰면 안 돼요. 내부 family를 PixelKo로 바꾸고 원저작권·OFL 원문·"Galmuri 기반 수정본" 표기를 동봉하면 조건을 만족해요 (OFL 1.1 §3, 정확도 높음 — 법적 자문 아님).
  • Bold가 필요하면(닉네임 강조 등) Galmuri11 Bold를 같은 절차로 PixelKo weight 700으로 추가할 수 있어요.

대안: Neo둥근모 원본 그대로

  • 44.6 kB에 수정 없이 쓸 수 있어 가장 간단해요. 대신 2x에서 32px라 말풍선 줄당 글자 수가 줄고 닉네임이 커요. GRAPHICS 5.2 최대 폭·5.3 닉네임 위치 수치를 다시 잡아야 해요.

3. 준비 절차 (추천안 기준)

  1. 원본 확보: npm pack galmuri → dist/Galmuri11.woff2, dist/LICENSE.txt. (CDN 로딩은 GRAPHICS 6장 "외부 자산 없음" 원칙에 어긋나므로 동봉)
  2. 부분집합 + 이름 변경 (개발 머신에서 1회, Python fontTools + brotli): 
    python3 -m venv .fonttools && .fonttools/bin/pip install fonttools brotli
.fonttools/bin/pyftsubset Galmuri11.woff2 \
  --unicodes="U+0020-007E,U+00A0-00FF,U+2000-206F,U+20A9,U+2190-21FF,U+2500-259F,U+25A0-25FF,U+3000-303F,U+3131-318E,U+AC00-D7A3,U+FF01-FF5E,U+FFE6" \
  --layout-features='*' --flavor=woff2 --output-file=PixelKo.woff2
# 내부 이름 변경 (name 테이블 1·4·6·16 → PixelKo), 저작권(0)·라이선스(13·14)는 유지
.fonttools/bin/python - <<'EOF'
from fontTools.ttLib import TTFont
f = TTFont('PixelKo.woff2')
for rec in f['name'].names:
    if rec.nameID in (1, 16): rec.string = 'PixelKo'
    if rec.nameID == 4: rec.string = 'PixelKo Regular'
    if rec.nameID == 6: rec.string = 'PixelKo-Regular'
f.flavor = 'woff2'; f.save('PixelKo.woff2')
EOF
    범위 설명: ASCII, Latin-1 보충(₩ 등 기호), 일반 문장부호, 화살표·박스·도형(UI 기호), CJK 문장부호(·「」), 호환 자모(ㄱㄴㄷ·ㅏㅑ), 한글 완성형 11,172자, 전각 문장부호. 이모지는 시스템 폰트 폴백(GRAPHICS 5.1)이라 넣지 않아요.
  3. 파일 배치 (GRAPHICS 6장): 
    src/assets/fonts/
├── PixelKo.woff2          # Galmuri11 부분집합·개명본 (~170 kB)
├── PixelKo-Bold.woff2     # 선택. Galmuri11 Bold 동일 절차
└── OFL-Galmuri.txt        # dist/LICENSE.txt 원문 그대로
src/assets/LICENSES.md     # 아래 항목 추가
    ## 폰트
- PixelKo: Galmuri11 (Copyright (c) 2019–2025 Lee Minseo, quiple.dev) 의 부분집합 수정본.
  SIL Open Font License 1.1, Reserved Font Name "Galmuri"는 수정본에 사용하지 않음.
  원문: src/assets/fonts/OFL-Galmuri.txt · 출처: https://github.com/quiple/galmuri (npm galmuri 2.40.3)
  변경: 한글·자모·라틴·문장부호 부분집합, 내부 family 명 PixelKo.
  4. CSS 등록 (7단계에서 src/index.css): 
    @font-face {
  font-family: 'PixelKo';
  src: url('./assets/fonts/PixelKo.woff2') format('woff2');
  font-weight: 400;
  font-display: block;      /* 픽셀 폰트가 시스템 폰트로 잠깐 바뀌면 배치가 튀므로 swap 대신 block */
}
:root { --pixel-font-em: 12px; }   /* Galmuri11 em. 표시 크기 = em × 줌 (2x → 24px) */
.bubble, .nickname { font-family: 'PixelKo', system-ui, sans-serif; font-size: calc(var(--pixel-font-em) * var(--zoom)); line-height: 1; }
    줌 변수는 uiStore.zoom을 --zoom으로 내려요. font-size는 항상 em × 정수 줌만 써요 (GRAPHICS 5.1).
  5. 검수 (자산 받을 때·빌드 후):
    • fontTools로 cmap 확인: 한글 U+AC00–D7A3 11,172자, ASCII 95자 전부 존재
    • name 테이블 family가 PixelKo이고 Galmuri 문자열이 1·4·6·16번에 없음 (0·13·14번의 저작권·라이선스 문구는 유지)
    • 파일 크기 ≤ 256 kB (GRAPHICS 6장 PNG 상한을 폰트에도 적용 제안)
    • 브라우저에서 24px(2x)·36px(3x)·48px(4x)로 "가나다 ABC 123 ·「」" 렌더 시 가장자리가 흐리지 않음 — 정수 배율만 쓰면 벡터화된 픽셀 폰트도 원본 도트로 떨어져요
    • Playwright에서 document.fonts.check("24px PixelKo")가 true (7단계 E2E에 포함 예정)

4. 사용자가 정할 것

  • 폰트 선택: 추천안(Galmuri11 부분집합·PixelKo) 또는 대안(Neo둥근모 원본). 정해지면 chat이 GRAPHICS 5.1에 기록하고(요청 파일 to-chat/2026-09-30-font-choice.md), Claude Code가 7단계 착수 시 위 절차로 파일을 만들어 커밋해요.
  • 직접 준비하실 필요는 없어요. 다른 폰트를 쓰고 싶다면 조건은 OFL 또는 CC0, 한글 11,172자(최소 KS X 1001 2,350자), em이 8~12px인 픽셀 폰트, woff2 ≤ 256 kB예요.
