2. CI에 넣지 않은 것

  • E2E(Playwright): 브라우저 설치와 Mock 서버 두 개를 띄우는 데 시간이 걸려 이번에는 넣지 않았어요(결정 A의 범위). 앞으로도 각 단계를 마치기 전에 제가 로컬에서 pnpm test:e2e를 돌려요. 필요해지면 PR에서만 도는 별도 잡으로 추가할 수 있어요.
  • 폰트 검수(scripts/fonts/check-font.py): Python fontTools가 필요하고 폰트를 바꿀 때만 의미가 있어서 넣지 않았어요. chat에도 알렸어요.

3. 첫 실행에서 나온 알림 (조치 불필요)

알림판단
"ubuntu-latest가 2026-10-19부터 Ubuntu 26으로 바뀐다"러너 OS가 바뀌어도 이 프로젝트는 Node·pnpm 버전을 직접 지정해서 영향이 적을 것으로 봐요(추정, 정확도 중간). 바뀐 뒤 실패하면 그때 ubuntu-24.04로 고정해요.
pnpm 설치 단계의 "pnpm v10 설치 흔적" 경고러너 이미지에 미리 깔린 pnpm 10의 흔적이에요. 실제 설치·실행은 pnpm 12.6.0으로 됐어요(로그로 확인). 무시해도 돼요.

4. 앞으로의 운영

  • CI가 실패하면 저장소의 Actions 탭에서 어느 단계가 실패했는지 바로 보여요. 제가 단계를 진행할 때는 푸시 후 CI 결과까지 확인하고 보고할게요.
  • 워크플로 파일을 바꾸는 푸시는 지금 토큰(workflow 권한 없음)으로는 GitHub가 거부해요. 워크플로를 고칠 일이 생기면 이번처럼 직접 푸시해 주시거나, 토큰에 workflow 권한을 더해 주세요. 그 밖의 코드·문서 푸시는 지금처럼 제가 해요.
  • pnpm 저장소 캐시를 첫 실행에서 저장했어요. 이후 실행은 의존성 다운로드가 줄어들어요. 잠금 파일이 바뀌면 새로 저장해요.
