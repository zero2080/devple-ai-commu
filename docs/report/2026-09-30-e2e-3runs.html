4. 발견 사항

중간Vite 설정 경고 (3회 모두)

(!) Your Vite config uses features that are unsupported by `configLoader: 'native'`,
    which is planned to become the default in a future major version of Vite:
  - import "./src/mocks/data/config" without a file extension (vite.config.ts:7:44). Add the file extension

vite.config.ts가 Mock 포트 목록을 확장자 없이 import해요. 지금은 동작하지만 Vite 다음 메이저에서 기본이 될 설정 로더는 이를 지원하지 않아 dev 서버가 뜨지 않을 수 있어요. 수정은 import 경로에 .ts를 붙이는 한 줄이에요.

낮음검증 범위의 한계

  • 브라우저: Chromium(headless)만 실행해요. PRD 6은 Chrome·Safari·Edge를 요구하므로 Safari 쪽(WebKit) 프로젝트 추가를 검토할 만해요. Edge는 Chromium 기반이라 위험이 낮아요.
  • 뷰포트: 데스크톱 기본 크기만 써요. 모바일 390×844 검증은 7단계 완료 조건으로 예정돼 있어요.
  • 표본: 3회 연속 통과는 간헐 실패가 드물다는 근거이지 없다는 증명은 아니에요. 더 확인하려면 아래 명령으로 반복 횟수를 늘리면 돼요.
