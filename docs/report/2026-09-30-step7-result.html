2. 이제 되는 것

  • 보내기: 월드에서 Enter → 입력창 → Enter로 전송. 한글 조합 중 Enter는 글자 확정으로만 쓰이고 전송되지 않아요. Esc로 캔버스에 돌아가요. 입력 중에는 방향키로 캐릭터가 움직이지 않고, 캔버스를 클릭하면 바로 이동할 수 있어요.
  • 받기: 반경 5타일(서버 설정값) 안의 발화만 받아요. 반경 판정은 서버(Mock)가 서버 위치 기준으로 해요.
  • 말풍선: 사람당 1개, 3초 + 글자당 50ms(최대 8초, 링크가 있으면 최소 6초). 링크 말풍선은 마우스를 올려 두면 사라지지 않아요. 픽셀 폰트 PixelKo, 1px × 줌 외곽선, 픽셀 꼬리예요.
  • 로그: 세션 동안 최근 200개. 보내는 중·실패 상태가 보이고, 실패하면 다시 보내기·지우기가 가능해요.
  • 링크: 서버가 준 links[]만 버튼으로 만들고 본문은 텍스트 그대로예요. 새 창은 opener·referrer 없이 열려요.
  • 화면 크기: 데스크톱은 20×15타일 이상, 모바일은 내 주변 11×11타일이 패널에 가려지지 않아요.
  • Mock: 가짜 접속자가 7초마다 근처에서 말해요(MOCK_CHATTER_MS). 개발용 POST /__mock/say로 특정 사람이 특정 위치에서 말하게 할 수 있어요.

5. 남은 것과 한계

확인 대기말풍선과 닉네임 위치 (chat 담당 GRAPHICS)

GRAPHICS 5.2(말풍선을 머리 위 4px에)와 5.3(닉네임을 머리 위 2px에)을 그대로 따르면 말풍선이 닉네임을 덮어요. 지금은 말풍선을 닉네임 위에 쌓는 안으로 구현했고, chat에 선택을 기록해 달라고 요청했어요(docs/handoff/to-chat/2026-09-30-bubble-nickname.md). 사용자 결정이 필요하면 chat이 알려줄 거예요.

한계알고 있는 것

  • 말풍선이 다른 캐릭터를 가려요. 스크린샷에서 팔비트의 말풍선이 내 캐릭터를 덮어요. 머리 위 말풍선 방식의 본질적인 겹침이라 이번엔 그대로 뒀어요. 필요하면 겹침 정렬(아래쪽 캐릭터 말풍선을 위로)이나 내 캐릭터 주변 비우기를 검토할 수 있어요.
  • 말풍선·패널 색은 Endesga 32 임시값이에요. 팔레트 확정(12단계) 때 바뀌어요.
  • E2E는 Chromium에서만 돌아요. PRD 6의 Safari는 아직 검증하지 않았어요.
  • Mock은 메시지 레이트 리밋(API_CONTRACT 1.4 권장값)을 흉내 내지 않아요. 클라이언트는 429 RATE_LIMITED를 실패 상태로 보여줄 수 있어요(단위 테스트로 확인).
  • DM 말풍선(보라 계열)·프로필 카드는 8단계예요.
