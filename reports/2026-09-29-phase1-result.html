진행 중 발견해서 고친 문제

문제처리
ROADMAP 버전표(Vite 5·Vitest 2·TS 5)가 현재 도구와 호환되지 않음npm 실측 후 React 19·Vite 8·TS ~6.0·Vitest 5·zod 4·msw 3로 갱신 (사용자 승인)
pnpm 12가 의존성 빌드 스크립트를 기본 차단pnpm approve-builds로 esbuild·unrs-resolver 허용, pnpm-workspace.yaml 커밋
import-x TS 리졸버 인터페이스 불일치eslint-import-resolver-typescript의 resolver-next 사용
gitignore식 부정 패턴으로는 domain 경계를 표현 불가no-restricted-syntax AST 셀렉터로 구현, 완료 조건에 검증 추가
erasableSyntaxOnly가 생성자 파라미터 프로퍼티를 거부필드 명시 선언으로 통일
zod optional 추론과 exactOptionalPropertyTypes 충돌 예상옵션 미사용으로 결정, 타입 동등성 테스트로 확인
msw 3 API 변경 (onUnhandledFrame, HttpResponse 제네릭 필수, 프레임 구조)타입 정의를 읽고 맞춤, 계약 경로만 경고하도록 조정
HANDOFF 반영 시 36개·선행 결정 참조 잔존 여부grep으로 확인, 엔드포인트 37개 재계산
Mock SSE 포트 5174를 다른 프로젝트 Vite가 점유, macOS에 timeout 없음MOCK_SSE_PORT 도입, 백그라운드 실행으로 스모크
Playwright webServer가 pnpm exec 자식을 못 죽여 매달림바이너리 직접 실행
getByLabel('접근 키')가 폼 제목까지 매칭textbox 역할로 셀렉터 좁힘
StrictMode 이중 effect로 티켓 2장, 부팅 refresh 401 콘솔 로그, MSW 쿠키 PathE2E 기준선·허용 규칙 조정, mock 쿠키 Path=/ (결정 리포트 3·4·8)
커밋 A에 스테이징된 삭제 파일이 섞여 들어감푸시 전 soft reset으로 문서만 담아 다시 커밋
